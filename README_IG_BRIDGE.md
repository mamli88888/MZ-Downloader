# MZ-Downloader — Instagram DM Bridge

این پکیج قابلیت **پل اینستاگرام** رو به ربات MZ-Downloader اضافه می‌کنه. با این
قابلیت، کاربر می‌تونه حساب اینستاگرامش رو به ربات وصل کنه و هر رییلز، پست یا
لینک اینستاگرامی که به دایرکت پیج شما می‌فرسته، توی تلگرام براش دانلود و ارسال
بشه.

## فایل‌ها

| فایل | وضعیت | توضیح |
|------|-------|-------|
| `ig_pairings.py` | جدید | مدیریت کدهای جفت‌سازی و نگاشت IG↔TG (با persistence) |
| `ig_bridge.py` | جدید | کلاینت instagrapi که به دایرکت‌های پیج گوش می‌ده |
| `ig_login.py` | جدید | اسکریپت یک‌بار مصرف برای لاگین اولیه و ساخت `ig_session.json` |
| `ig_session.py` | جدید | helper ساخت instagrapi.Client با پشتیبانی curl_cffi (رفع ارور SSL) |
| `bot.py` | تغییر | افزودن دستورات `/ig` و `/igunlink`، استارت/استاپ IG bridge در `post_init`/`post_shutdown` |
| `config.py` | تغییر | افزودن `IGBridgeConfig` و فیلد `ig_bridge` به `Settings` |
| `.env.example` | تغییر | افزودن متغیرهای `IG_BRIDGE_*` |
| `requirements.txt` | تغییر | افزودن `instagrapi==2.1.5` و `curl_cffi>=0.7.0` |

سایر فایل‌های پروژه (`downloader.py`, `routing.py`, `users_db.py`, ...) دست‌نخورده
هستن. فقط این ۸ فایل رو جایگزین/اضافه کن.

## نحوه کار

1. کاربر در تلگرام دستور `/ig` رو می‌فرسته.
2. ربات یک کد ۶ کاراکتری اختصاصی (مثل `MZ8X4K`) بهش نشون می‌ده.
3. کاربر اون کد رو به دایرکت پیج اینستاگرام شما (که ربات بهش وصله) می‌فرسته.
4. ربات کد رو می‌بینه، حساب اینستاگرام کاربر رو به Telegram ID اون وصل می‌کنه و
   توی همون دایرکت IG تایید می‌فرسته.
5. از این به بعد، هر پیامی که کاربر به دایرکت پیج بفرسته:
   - اگه لینک اینستاگرام (reel/p/tv/stories) داشته باشه → استخراج می‌شه
   - اگه رییلز/پست فوروارد شده باشه → لینکش از `media_share` استخراج می‌شه
   - لینک از طریق همان فلوی دانلود موجود (پشتیبان‌بات‌ها) پردازش می‌شه
   - نتیجه توی تلگرام براش ارسال می‌شه

## راه‌اندازی

### ۱. نصب وابستگی‌های جدید

```bash
pip install instagrapi==2.1.5 curl_cffi>=0.7.0
```

یا با `requirements.txt` آپدیت‌شده:

```bash
pip install -r requirements.txt
```

> **نکته مهم**: `curl_cffi` برای عبور از fingerprint TLS اینستاگرام ضروریه. بدون
> اون، تقریباً مطمئنه با ارور `SSLEOFError` روبرو می‌شی (مخصوصاً روی urllib3 v2).

### ۲. ساخت پیج اینستاگرام

یک پیج اینستاگرام جدید بساز (مثلاً `@your_page_name`). این پیج قراره دایرکت‌ها رو
بگیره، پس اکانت باید قابل دسترسی باشه (پابلیک باشه یا حداقل قابلیت دریافت DM از
همه رو روشن داشته باشه).

### ۳. لاگین اولیه (یک‌بار)

این کار رو **روی سیستم محلی** (نه سرور) انجام بده تا Instagram مشکوک نشه:

```bash
# روی سیستم محلی:
pip install instagrapi python-dotenv curl_cffi

# متغیرهای محیطی رو ست کن:
export IG_BRIDGE_USERNAME=your_page_name
export IG_BRIDGE_PASSWORD=your_password
# اختیاری ولی توصیه‌شده تو ایران:
export IG_BRIDGE_PROXY=socks5://127.0.0.1:10808
# یا http://user:pass@host:port

# اسکریپت لاگین:
python3 ig_login.py
```

اگه 2FA یا Challenge بخواد، اسکریپت interactive ازت کد می‌گیره. بعد از موفقیت، فایل
`ig_session.json` ساخته می‌شه.

### ۴. انتقال session به سرور

فایل `ig_session.json` رو به همون مسیر `bot.py` روی سرور کپی کن.

### ۵. فعال‌سازی روی سرور

در `.env` سرور:

```env
IG_BRIDGE_ENABLED=true
IG_BRIDGE_USERNAME=your_page_name
# password فقط برای لاگین اول لازم بود؛ حالا که session هست، می‌تونی خالی بذاری
IG_BRIDGE_PASSWORD=
IG_BRIDGE_SESSION_FILE=ig_session.json
# اختیاری: پراکسی برای API های اینستاگرام
# IG_BRIDGE_PROXY=socks5://127.0.0.1:10808
```

### ۶. ری‌استارت ربات

```bash
python3 bot.py
```

در لاگ‌ها باید ببینی:
```
IG bridge started for @your_page_name (my IG user_id=...); polling every 8s.
```

اگه غیرفعال باشه:
```
IG bridge disabled (IG_BRIDGE_ENABLED=false).
```

## تست

1. ربات رو در تلگرام استارت بزن.
2. دستور `/ig` بزن. باید کد ۶ کاراکتری ببینی.
3. با اکانت اینستاگرام شخصیت (نه پیج ربات)، به دایرکت پیج ربات برو و اون کد رو بفرست.
4. باید تایید بگیری (هم توی دایرکت IG، هم توی تلگرام).
5. حالا یک رییلز یا پست اینستاگرام رو به دایرکت پیج فوروارد کن.
6. باید توی تلگرام، پیام «📥 از دایرکت اینستاگرام» + دانلود رو ببینی.

## محدودیت‌ها و نکات

- **Stories**: استوری‌ها لینک عمومی ندارن، بنابراین از طریق این پل قابل دانلود
  نیستن. کاربر پیام راهنما می‌گیره که بگه لینک reel/p بفرسته.
- **نرخ polling**: هر ۸ ثانیه یک‌بار چک می‌شه. Instagram اگه نرخ خیلی بالا باشه
  ممکنه حساس بشه. ۸ ثانیه امنه.
- **Session expiry**: session های Instagram معمولاً ۱-۳ ماه دوام میارن. اگه منقضی
  شد، دوباره `ig_login.py` رو روی سیستم محلی اجرا کن و `ig_session.json` جدید رو
  کپی کن.
- **تعقیب Instagram**: اگه پیج خیلی فعال باشه یا از IP مشکوک لاگین بشه، Instagram
  ممکنه چالج بذاره. بهتره از پراکسی استفاده کنی (`IG_BRIDGE_PROXY`).
- **Rate limit دایرکت**: اگه هزاران کاربر هم‌زمان پیام بفرستن، Instagram ممکنه
  throttle کنه. این نسخه برای استفاده متوسط طراحی شده.

## عیب‌یابی

**ارور `SSLEOFError` / `UNEXPECTED_EOF_WHILE_READING` هنگام لاگین**

این ارور به این معنیه که Instagram کانکشن TLS شما رو به خاطر fingerprint غیررسمی
رد کرده. سه راه‌حل، به ترتیب اولویت:

1. **نصب `curl_cffi`** (اولین و مهم‌ترین راه‌حل):
   ```bash
   pip install curl_cffi
   ```
   این کتابخانه fingerprint کامل Chrome رو impersonate می‌کنه و Instagram رو فریب
   می‌ده. کد به طور خودکار ازش استفاده می‌کنه اگه نصب باشه.

2. **استفاده از پراکسی** (اگه تو ایران/چین/روسیه هستی، ضروریه):
   ```bash
   export IG_BRIDGE_PROXY=socks5://127.0.0.1:10808
   # یا http://user:pass@host:port
   ```
   بدون پراکسی، هیچ TLS impersonation‌ای کمکت نمی‌کنه چون middlebox ایران قبل
   از تکمیل handshake کانکشن رو می‌بنده.

3. **Downgrade urllib3** (آخرین راه‌حل، اگه curl_cffi نصب نمی‌شه):
   ```bash
   pip install "urllib3<2"
   ```
   urllib3 v1 رفتار SSL متفاوتی داشت که کمتر حساس بود.

**"IG bridge failed to start"**
- لاگ‌ها رو چک کن. معمولاً یا session فایل موجوده ولی نامعتبره (دوباره `ig_login.py` اجرا کن)، یا Instagram چالج گذاشته.
- اگه `IG_BRIDGE_USERNAME` خالی باشه هم این اتفاق می‌افته.

**"direct_threads failed: ..."**
- احتمالاً session منقضی شده. `ig_session.json` رو پاک کن، دوباره `ig_login.py` اجرا کن، session جدید رو کپی کن.
- اگه ارور SSL دیدی، مطمئن شو curl_cffi نصبه و `IG_BRIDGE_PROXY` روی سرور ست شده.

**کاربر کد می‌فرسته ولی اتفاقی نمی‌افته**
- مطمئن شو کاربر به همون پیج DM می‌فرسته که توی `IG_BRIDGE_USERNAME` تنظیم شده.
- اگه کاربر اکانت private داره یا message requests رو بسته، پیامش ممکنه به جای inbox به message requests بره و دیده نشه. تو تنظیمات پیج، «Allow message requests from everyone» رو روشن کن.

**دانلود از لینک کار نمی‌کنه**
- این فلوی دانلود همان فلوی اصلی ربات هست. اگه پشتیبان‌بات‌ها مشکل دارن، اینجا هم مشکل پیدا می‌کنه. با یک لینک مستقیم در تلگرام تست کن تا مطمئن شی فلوی اصلی کار می‌کنه.

## خلاصه تغییرات

این پکیج ۸ فایل داره (۴ فایل جدید + ۴ فایل تغییر یافته) و هیچ فایل موجودی
حذف یا تغییر اساسی نشده. اگه قابلیت رو خواستی غیرفعال کنی، کافیه `IG_BRIDGE_ENABLED=false`
بذاری و ربات رو ری‌استارت کنی — هیچ اثر جانبی روی بقیه قابلیت‌ها نداره.
